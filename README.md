# 🎨 NFT Marketplace Landing Page

A modern, high-performance, and fully responsive NFT Marketplace landing page built with a focus on clean UI/UX and dark-themed aesthetics.

## 🚀 Live Demo

## ✨ Features

- **Modern Dark UI:** Optimized for the crypto and digital art community.
- **Fully Responsive:** Seamlessly works across mobile, tablet, and desktop devices.
- **Interactive Components:** Features sections for Wallet connection, Hot Bids, Top Creators, and Trend tracking.
- **RTL Support:** Optimized for Right-to-Left languages (built using Bootstrap RTL).
- **Clean Code Architecture:** Organized folder structure for easy maintenance and scalability.

## 🛠 Built With

- **HTML5:** Semantic structure for better SEO and accessibility.
- **CSS3:** Custom styles including gradients and modern layouts.
- **Bootstrap 5:** For a robust grid system and pre-styled components.
- **JavaScript:** For interactive elements and layout functionality.

## 📂 Project Structure

